# ✦ Starweave 界面导览

从一个智能体，到一支协作队伍，再到任务、观测与外部世界——这里按使用路径展示当前控制台。
截图由 Open Code Skill 于 **2026-10-11** 整理；[返回 README](../README.md) 查看功能说明与快速上手。

桌面截图为 1920 × 1080；移动端图片来自 Chrome iPhone SE 设备模拟，CSS 视口为 375 × 667，
并非真机拍摄。截图展示的是当时的界面状态：普通会话尚无聊天内容，企微渠道列表为空，网关处于停止状态。
